Tooltips

Tooltips are available in different flavors.

On this screen, all tooltips are displayed by default to make it easier to preview all declinations. Hovering on a text will make the tooltip disappear after mouse leave: the tooltip will then behave as a classical tooltip.

You can also hide/show all tooltips by clicking those buttons:
