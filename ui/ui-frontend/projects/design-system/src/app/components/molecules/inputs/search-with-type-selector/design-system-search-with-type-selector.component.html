Search with type selector

This is a form component that mixes a "type" selection and a normal input.

The purpose of this component is to be able to specify the type of search (fuzzy, exact, ...) in addition to the term to search.

Default

Default instance of the component. The first type in the list is used by default.

Active

"Active" version of the component: when the component is focused, borders change to primary color.

Also, we put an initial value both for the type selector and the input value.

Disabled

Disabled version of the component: no interaction is possible and the background color is grey.

A "type" can be disabled in the type selector.

Error

Validators.required validator is automatically applied to the "input" part of the component.

If you need to use other validators, make sure to write a custom validator that applies the validation on the "value" (or the "type") returned by this component.

Wrapper

The component is wrapped in another component that requires validating/cancelling the filled value before "emitting" it.

Value: {{ wrapperControl.value | json }}
