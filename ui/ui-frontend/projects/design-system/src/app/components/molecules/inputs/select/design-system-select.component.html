Select

This is a form component that allows the user to select an option from a list of options. The component can be configured:
  • to display a search bar filtering the options
  • to allow selecting multiple options (multiple mode)
    • to have a "select all" option (in multiple mode)
    • to manage selected options in a "cart" (in multiple mode)
